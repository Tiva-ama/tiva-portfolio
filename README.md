# Portfolio — Tiwarat Amarit

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าหลัก — Home / About / Work / Projects / Contacts |
| `project.html` | หน้ารายละเอียดผลงาน ใช้ไฟล์เดียวกับทุกโปรเจกต์ อ่านคีย์จาก `?p=` |
| `cv.html` | หน้า CV จัดหน้าให้สั่งพิมพ์เป็น PDF ขนาด A4 ได้พอดีหน้าเดียว |
| `style.css` | สไตล์ของหน้าหลักและหน้าผลงาน |
| `script.js` | เอฟเฟกต์ตอนเลื่อน แท็บ ป๊อปอัพใบรับรอง และตัวเล่นเพลง |
| `img/` | ภาพผลงานและใบรับรอง |

## เพิ่มผลงานใหม่

1. เติมข้อมูลอีกหนึ่งก้อนใน `PROJECTS` ที่ `project.html`
2. ก๊อปการ์ดใน `index.html` แล้วชี้ลิงก์มาที่ `project.html?p=<คีย์ที่ตั้งไว้>`

หัวข้อไหนไม่มีข้อมูล ลบทิ้งได้ หน้าจะข้ามให้เอง

## หมายเหตุ

- ภาพหน้าจอของระบบที่ทำในที่ทำงานเป็น **ภาพจำลอง ข้อมูลสมมติทั้งหมด** ไม่ใช่ภาพจากระบบจริง
- เว็บยังอ่านได้ครบแม้เบราว์เซอร์ไม่รัน JavaScript
- ออกแบบทิศทาง เลือกธีม และเขียนเนื้อหาเอง ส่วนโค้ดพัฒนาร่วมกับผู้ช่วย AI
